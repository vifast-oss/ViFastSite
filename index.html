ViFast — phần mềm Việt, nhỏ và nhanh

Ba dự án mã nguồn mở do một người Việt làm: bộ gõ tiếng Việt, giọng đọc tiếng Việt và một hệ điều hành microkernel. Tất cả chạy local, mã nguồn mở theo giấy phép MIT.

Ba dự án

Three projects, one small stack

ViFastKey

Bộ gõ tiếng Việt hỗ trợ Telex, Simple Telex, VNI và VIQR. Lõi Rust rất nhỏ, chạy hoàn toàn local, có C ABI, WASM, API Python và demo UEFI x86_64.

  • Rust
  • WASM
  • C ABI
  • UEFI demo
  • MIT
Mở key.vifast.org GitHub ↗

ViFastTts

Giọng đọc tiếng Việt chạy trên CPU với ONNX acoustic và vocoder. Chạy local ngay trong trình duyệt qua WASM + ONNX Runtime Web; không gửi văn bản hay model ra ngoài.

  • ONNX
  • CPU
  • WASM
  • offline
  • MIT
Mở tts.vifast.org GitHub ↗

ViFastOs

đang phát triển • đăng ký sớm

Hệ điều hành microkernel kiểu seL4 viết bằng Rust. Capability-based, kernel no_std và #![forbid(unsafe_code)], IPC + notification, chạy trên QEMU với ba kiến trúc riscv64 / aarch64 / x86_64.

  • Rust
  • no_std
  • capability
  • riscv64
  • aarch64
  • x86_64
  • MIT
Mở os.vifast.org GitHub ↗

Vì sao ViFast

Why ViFast

  • nhỏ — ít phụ thuộc

    Mỗi dự án chỉ giữ phần cần thiết: không framework, không runtime nặng, không phụ thuộc dịch vụ bên ngoài.

  • nhanh — chạy local, không round-trip server

    Xử lý ngay trên máy hoặc trong trình duyệt. Không gửi dữ liệu lên server, không có round-trip mạng.

  • mở — mã nguồn MIT trên GitHub vifast-oss

    Toàn bộ mã nguồn công khai tại github.com/vifast-oss, giấy phép MIT.

Vì sao tên ViFast

Ba chữ, ba ý — và cả ba đều đúng với cách ViFast được viết.

Vi — Việt Nam

Làm bởi người Việt, cho tiếng Việt: bộ gõ Telex/VNI, giọng đọc tiếng Việt, và một hệ điều hành viết từ đầu. Màu đỏ và ngôi sao vàng là chủ ý, không phải trang trí.

Vi — "vi xử lý" (micro)

“Vi” còn là vi trong vi xử lý — tức là nhỏ. ViFastKey giữ lõi Rust gọn, ViFastTts chạy model ONNX ngay trên CPU, ViFastOs giữ kernel no_std với hạn mức tĩnh rõ ràng thay vì phình to.

Fast — nhanh

Lõi viết bằng Rust, biên dịch thẳng ra mã máy native — không máy ảo, không garbage collector. ViFastKey và ViFastOs chạy mã native trực tiếp; ViFastTts dùng nhân ONNX Runtime native cho model, phần điều phối cũng bằng Rust. Nên “nhanh” là nhanh đo được: gõ không round-trip server, giọng đọc chạy local, kernel chỉ một lock toàn cục và số syscall đếm được.
